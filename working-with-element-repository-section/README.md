# Element Repository

The **Element Repository** in Avo Assure is a centralized location for creating, capturing, storing, and managing User Interface (UI) elements used across your tests. You can capture an element once, save it to the repository, and reuse it across multiple test cases. This reduces duplication of effort, simplifies test maintenance, and promotes consistency when building and updating automated tests. This article explains how to create and manage Element Repositories and introduces the key features available.
