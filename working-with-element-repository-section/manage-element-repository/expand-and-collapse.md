# Expanding and Collapsing Folders

To expand and collapse the folders, perform the following actions:

1. On **Home** page, from **Projects** list, select required project.
2. Select **Design Studio**.
3. On **Element Repository** page, select expand (**>**). All the sub folders and element repositories display.

<figure><img src="../../../../.gitbook/assets/image (1813).png" alt=""><figcaption></figcaption></figure>

4. Select collapse. All the sub folders and element repositories collapse.
