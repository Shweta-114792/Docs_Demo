# Viewing Screenshot

The View screenshot feature allows users to highlight the elements captured from the application under test (AUT).&#x20;

To view screenshot of the elements, perform the following actions:&#x20;

1. On the **Home** page, from **Projects** list, select required project.
2. Select **Design Studio**.
3. On the **Element Repository** page, select folder and element repository.
4. From **Screenshots** column, select **View Screenshot** to view screenshot of that element.

5. Select **View Screenshot** to view the screenshot of the element.&#x20;
