# Element Identifier Order

**Element identifiers** are the attributes that Avo Assure uses to locate UI elements during test execution. Since an element can have multiple identifiers, you can configure their priority by defining the **Element Identifier Order**. Using an appropriate identifier order improves element recognition, enhances execution reliability, and helps reduce failures caused by changes in the application. This section introduces the available element identifiers, explains their purpose, and describes how to configure their order for individual elements or across an entire Element Repository. This article explains what element identifiers is and how reorder identifier priority using available options in the Element Repository.
