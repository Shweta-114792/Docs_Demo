# Selenium To Avo

The Selenium to Avo feature helps you migrate existing Selenium automation scripts into Avo Assure Test cases. Avo Assure currently supports Selenium scripts written in Java and JavaScript. To use this feature, your Selenium automation scripts must be written in one of these supported languages.
