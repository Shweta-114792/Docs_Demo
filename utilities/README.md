# Utilities

The Utilities in Avo Assure provides essential tools to secure and accelerate your testing workflow. These features enable you to manage sensitive data through authorization and encryption, handle data tables efficiently, and migrate existing scripts from external tools into Avo Assure.

## This Article Contains the Following Modules

[Encryption](encryption.md)\
Learn how to encrypt and decrypt sensitive data values.

[Authorization](authorization.md)\
Learn how to generate the Auth Token.

[Migrate To Avo](migration-to-avo/)\
Learn how to migrate non avo script to Avo Assure.

[Data Parameterization](../create-and-execute-tests-with-design-studio/working-with-test-case-section/features-in-test-case-section-1/data-parametrization/)\
Learn how to data parameterize the data.
