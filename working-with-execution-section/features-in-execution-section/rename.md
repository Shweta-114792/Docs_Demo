# Rename

## Rename Folder

Steps to rename the Folder:

1. On the **Execution** tab, select folder and select ellipsis icon **(...)**.
2. Select **Rename** to rename the created folder.

## Rename Execution List

Steps to rename the Execution List:

1. On the **Execution** tab, select folder and select ellipsis icon **(...)**.
2. Select **Rename** to rename the created Execution List.
