# Searching Folders and Execution Lists

The **Search Folders / Execution Lists** feature allow you to search the created folders and execution lists.

To search folders and execution lists, perform the following actions:

1. On the **Home page**, under **Projects**, select desired project form the list and select **Design Studio**.
2. Select **Execution** tab.
3. On the left panel, select **Search Folders / Execution Lists**.
4. Enter the create Execution List name in the search box. The matching folders and execution lists highlight in orange.
