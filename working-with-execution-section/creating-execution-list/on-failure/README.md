# On Failure

**Avo Assure** provides a feature within the **Execution List** that allows users to define how the execution should proceed when a test step fails. This setting can be applied across all test cases or to the entire execution list, offering enhanced flexibility and control over the execution flow. It is especially useful in scenarios where both unpredictable steps are present, enabling users to manage failures without disrupting the overall test process.
