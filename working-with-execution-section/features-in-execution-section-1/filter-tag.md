# Filter Tag

The **Filter Tag** feature allows users to group Testcases under a single tag. The tagged Testcases can then be added to the Execution List. Within the Execution List, you can use the **Filter Tag** option to easily view and manage Test Cases associated with a specific tag.

Step-by-step process to add tagged Testcases to the Execution List:

1. On the **Execution** tab, select **Execution List** and select the **Add Test Case**.
2. Select the **Filter Tag** icon located below the search box in the Test Case section.

<figure><img src="../../../.gitbook/assets/image (4364).png" alt=""><figcaption></figcaption></figure>

2. Search or select the tags from the dropdown.

{% hint style="info" %}
**Note**: You must create the Tags in the **Test Case** tab. To learn how to create Tags, refer to [**Tag Test Case**](/broken/pages/8zlcQatR6Shtym7IOHKX).
{% endhint %}

<figure><img src="../../../.gitbook/assets/image (4318).png" alt=""><figcaption></figcaption></figure>

3. Once you select a Tag(s), you see all the Testcase(s) that are associated with that tag.

<figure><img src="../../../.gitbook/assets/image (4319).png" alt=""><figcaption></figcaption></figure>

4. Drag and drop the Testcase from **Test Cases** window into the Execution List.
