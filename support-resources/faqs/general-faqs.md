# General FAQs

Use this section to view the common questions about the basic capabilities and usage of Avo Assure. It includes queries about common doubts related to the platform, its core functionality, and general usage.

* **Can Avo Assure automate testing for multiple technologies?**\
  **Ans**: Yes. Avo Assure supports automation across various technologies such as web applications, APIs, Desktop Applications, Databases, Mainframe and MS Dynamics 365.
*   **Can multiple users work on the same project in Avo Assure?**

    **Ans**: Yes. Users can collaborate on the same project based on their assigned roles and permissions.
*   **Can Avo Assure integrate with other tools in the testing lifecycle?**

    **Ans**: Yes. Avo Assure supports integrations with various tools used in the testing lifecycle, such as CI/CD tools and test management systems. For example: Jenkins, Docker, Harness and Azure DevOps.
