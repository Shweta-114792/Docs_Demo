# Integrations

Use this section to view common questions related to integrations. It includes queries about connecting with third-party tools, configuring integrations, and managing data exchange.

**Q**: **Can Avo Assure integrate with CI/CD tools?**\
**Ans**: Yes. Avo Assure can integrate with CI/CD tools such as [Jenkins](../../integrations-in-avo-assure/devops-integration/http-request/ci-cd-jenkins/jenkins-integration/) and [Azure DevOps](../../integrations-in-avo-assure/test-management/azure-devops-in-avo-assure/logging-bug-in-azure-devops/) to run automated tests during the deployment process.&#x20;

**Q**: **Can Avo Assure integrate with test management tools?**\
**Ans:** Yes. Avo Assure can integrate with[ Jira ](../../integrations-in-avo-assure/test-management/jira-integration/)and other test or defect management tools.
