# Element Repository

Use this section to view common questions related to the Element Repository. It includes queries about creating, managing, organizing, and reusing elements across test cases.

*   **Can I reuse elements across multiple test cases in Avo Assure?**

    **Ans**: Yes. Elements stored in the Element Repository can be reused in multiple test cases.
*   **Can I modify an element in the repository after it is created?**

    **Ans**: Yes. You can modify element properties in the repository whenever changes occur in the application UI, such as updates to locators or element attributes.
