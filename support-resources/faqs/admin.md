# Admin

Use this section to view common questions related to administrative configurations. It includes queries about user management, roles and permissions, and system-level settings.

* **Does the Admin section automatically grant access to new users without configuration?**\
  **Ans**: No. Administrators must create user accounts and assign roles before new users access the platform.
*   **Is it mandatory for all user roles to have access to the Admin section?**

    **Ans:** No. Only users with the **Admin** role and **Quality Manager** users with **Admin as a secondary role** can access the Admin section and configure its settings.
*   **Does the Admin section allow modification of existing user details?**

    **Ans**: Yes. Administrators can update user details such as role assignments, Username, and Password.
