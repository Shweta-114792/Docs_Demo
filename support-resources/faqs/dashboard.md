# Dashboard

Use this section to view common questions related to the Dashboard. It includes queries about viewing metrics, tracking progress, and understanding key insights.

* **Does the Dashboard display the overall health of a particular project?**\
  **Ans:** Yes. Dashboard displays the overall health of a project by monitoring the Element Repository, Test cases, and Execution results.
* **Does the Dashboard monitor the effort spent on a particular project by a user?**\
  **Ans:** Yes. Dashboard monitors the effort spent by users on a particular project using pie charts and bar graphs.
