# Learning Catalogs

Browse through the different offerings in the learning programs on [Avo Academy](https://www.avoautomation.com/academy), along with the topics covered in each course. You will find descriptive explanations of the features as well as demos and detailed workbooks to compliment the features of Avo Assure.

## [Avo Assure Administrator](https://learningmanager.adobe.com/app/learner?accountId=122416#/course/14443271)

This course is designed for users responsible for managing platform-level configurations within the Avo Assure environment. It explains how administrators control system access, manage users and roles, and configure administrative settings that govern how the platform is accessed and used across the organization.

## Automating Web Apps with Avo Assure
