# Resolving Browser Compatibility Error

| Browser compatibility error: The browser version is not supported, and this error is being displayed in the client.  | <ul><li>The browser (Edge/Chrome) was updated to the latest version.  </li><li>The corresponding browser drivers (e.g., Edge driver) were outdated.  </li><li>The Avo Assure client version was older than the latest version.  </li><li>A version mismatch between the browser, driver, and client caused the execution failure. </li></ul> | <ul><li>Update the Avo Assure client to the latest available version. </li><li>Ensure browser drivers are updated to match the installed browser versions. </li><li>Restart the Avo Assure client after updates and retry test case capture/execution. </li></ul><p> </p> |
