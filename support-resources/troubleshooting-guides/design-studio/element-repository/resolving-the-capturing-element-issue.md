# Resolving the Capturing Element Issue

| Unable to capture the element, the capture window is not opening. | <ul><li>Version mismatch between the Avo Assure client and the Avo Assure instance  </li></ul> | <ul><li>Ensure that the Avo Assure client version matches the server instance version. If there is a mismatch, update the client to the latest version, relaunch the application, and retry the execution.</li><li>If the issue persists after performing the above steps, uninstall and reinstall the client with a fresh installation.</li></ul> |
