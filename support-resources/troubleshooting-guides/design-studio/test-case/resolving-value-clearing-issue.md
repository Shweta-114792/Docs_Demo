# Resolving Value Clearing Issue

| **Set Text Action** does not work as expected. Values are entered but get cleared instantly.   | <ul><li>The target element does not have focus when the action runs.  </li><li>The application does not support direct text setting (e.g., copy-paste restriction). </li></ul> | <ul><li>Ensure the element is in focus before setting text.  </li><li> If direct Set Text fails, use Send Keystrokes to input the value.  </li><li>Try adding a Click on Element or Set Focus action before Set Text.  </li><li>If the issue persists, recapture the UI element. </li></ul> |
