# Clicking On a Table Cell

| Unable to click on a table cell using the **Click on Table Cell** action in the application.  | <ul><li>The specified row or column is invalid for Click action </li><li>The specified row or column is hidden in the table </li><li>The table is not fully loaded in the application. </li></ul><p> </p> | <ul><li>Ensure the table is fully loaded in the application.  </li><li> If the table contains hidden cells, use the Get Row Number by Text action to retrieve the correct row number.  </li><li>Use the output from the Get Row Number by Text action as input for the Click on Table Cell action. </li></ul> |
