# Element Repository

Use this section to learn tips and tricks for working with the Element Repository. These help you to create, manage, reuse, and update elements to support stable and maintainable test automation.

<details>

<summary><strong>Enable Self-Healing for Dynamic UI Elements</strong></summary>

Enable **Self-Healing** with **Custom Attributes** in the element details to improve element identification when UI attributes change dynamically, resulting in more stable test executions.

</details>

<details>

<summary><strong>Use Custom Properties for Reliable Element Identification</strong></summary>

Configure [**Custom Properties**](../../../create-and-execute-tests-with-design-studio/working-with-element-repository-section/features-in-element-repository/element-identifier-order/custom-property/) to define additional element attributes when default attributes are insufficient, improving the accuracy and reliability of element identification.

</details>
