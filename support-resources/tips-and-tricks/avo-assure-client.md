# Avo Assure Client

Use this section for effectively using the client settings in Avo Assure. These suggestions help you to ensure smooth communication between the server and client machine and optimize overall test execution performance.

<details>

<summary><strong>Configure the Global Time-Out for Stable Test Execution</strong></summary>

Increase the **Global Time-Out** value in **Avo Assure Client Settings** to slightly exceed your application's average response time to prevent false test failures caused by temporary network or server delays.

</details>

<details>

<summary><strong>Clear Stale Browser Processes Before Execution</strong></summary>

Use the **Kill Stale Process** option in the **Avo Assure Client** before starting a new execution to close leftover browser processes and ensure a clean execution environment.

</details>

<details>

<summary><strong>Use Stepwise Debugging to Isolate Test Failures</strong></summary>

Use **Stepwise Debugging** to execute test steps one at a time, making it easier to identify failing steps, validate object interactions, and troubleshoot synchronization or timing issues efficiently.

</details>
