# Opening Artefacts in New Tab

The Open in new tab option helps you open a duplicate of the current Avo Assure instance in a new tab within the same browser. This feature allows you to work on multiple pages simultaneously without navigating from your current page. This article covers how to open the current Avo Assure instance in a new browser tab.

To open Avo Assure page in a new tab, perform the following actions:

1. On the **Home** page, under **Projects**, select the required project.
2. Select **Design Studio**.
3. Select the **Ellipses** (**...**) menu for the required artefact.
4. Select **Open in new tab**. The selected artefact opens in a new browser tab.

{% hint style="info" %}
**Note**: You can also open the current page in a new browser tab by copying the URL from the browser's address bar and pasting it into a new tab.
{% endhint %}
