# Copy & Paste

**Copy Test steps**&#x20;

Step-by-step process to copy test steps in Test case&#x20;

1. Navigate to Test Cases window&#x20;
2. Select Test step and click Copy icon located in top right pane of screen&#x20;

**Paste Test steps**&#x20;

Step-by-step process to paste Test steps &#x20;

1. Navigate to Test Cases window&#x20;
2. Select the desired Test step and click Paste icon from the top right pane of screen &#x20;
