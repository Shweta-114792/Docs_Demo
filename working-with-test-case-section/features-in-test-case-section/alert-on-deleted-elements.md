# Alert on Deleted Elements

When elements are deleted from a Test Step Group, a warning message appears each time you view that Test Step Group.

To locate and edit the Deleted Object’s step perform the following actions:

1. On **Home** page, under **Projects**, select required project.
2. From upper right corner, select **Design Studio** to open the **Test Case** page.
3. Select the **Test Case** for which an element is deleted, and you can see the Warning message.

<figure><img src="../../../.gitbook/assets/unknown (111).png" alt=""><figcaption></figcaption></figure>

3. Locate the Test Step Group which have **Warning** icon.

<figure><img src="../../../.gitbook/assets/unknown (114).png" alt=""><figcaption></figcaption></figure>

5. Select the **Warning** icon. Deleted Elements steps are automatically selected.

<figure><img src="../../../.gitbook/assets/unknown (116).png" alt=""><figcaption></figcaption></figure>

6. Modify the step with correct element.
7. Select **Save** button

{% hint style="info" %}
**Note**:

* If a Test Step Group is reused, the icon appears in the **Reusable Library** section.
* If a reused Test Step Group is detached, the icon will appear on both - the Test Step Group in the Reusable Library and the detached Test Step Group.
{% endhint %}
