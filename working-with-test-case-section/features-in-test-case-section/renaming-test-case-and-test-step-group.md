# Renaming Test Case and Test Step Group

## Renaming Test Case

To rename the Test case, perform the following actions:

1. On the **Home** page, from **Projects** list, select required project.
2. Select **Design Studio**.
3. Select **Test Case** page.
4. Expand required folder and select the Test case.
5. Select ellipses(**...**) icon.

<figure><img src="../../../../../.gitbook/assets/Ellipses.png" alt=""><figcaption></figcaption></figure>

6. Select **Rename** to rename the Test case.

<figure><img src="../../../../../.gitbook/assets/rename test case.png" alt=""><figcaption></figcaption></figure>

## Renaming Test Step Group

To rename the Test Step Group, perform the following actions:

1. On the **Home** page, from **Projects** list, select required project.
2. Select **Design Studio**.
3. Select **Test Case** page.
4. Expand required folder and select the Test case.
5. Single click on Test Step Group and rename it.
