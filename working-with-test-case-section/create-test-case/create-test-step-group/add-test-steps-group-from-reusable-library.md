# Add Test Step Group from Reusable Library

Below is the stepwise process to create Test steps group from Reusable Library:&#x20;

1. Click **Create Test Step Group** button and select **Add new test step Group.**
2. In the Test Step Group pop-up. Click on **drop-down icon** from **Add test step group from Reusable Library.**&#x20;
3. **Select "Login"**

<figure><img src="../../../../.gitbook/assets/image (1826).png" alt="" width="533"><figcaption></figcaption></figure>

4. Choose **Application Type**. Click **Create.**

<figure><img src="../../../../.gitbook/assets/image (1827).png" alt="" width="527"><figcaption></figcaption></figure>

5. Test Step group will be created with Reusable library.
