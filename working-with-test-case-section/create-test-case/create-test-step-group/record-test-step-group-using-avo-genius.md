# Record Test Step Group Using Avo Genius

To record test step group using Avo Genius follow the steps:

### Design Studio

**Web Application**

1. Click on **New test step group** and select **Record new test step group**

<figure><img src="../../../../.gitbook/assets/image (1829).png" alt="" width="563"><figcaption></figcaption></figure>

2. Avo genius window will pop-up. Select **Application type as WEB** and **Provide Application URL. Click Start Recording.**

<figure><img src="../../../../.gitbook/assets/image (1757).png" alt="" width="563"><figcaption></figcaption></figure>

3. Avo Genius recording window will pop up. Click on the elements to add them

<figure><img src="../../../../.gitbook/assets/image (1758).png" alt="" width="425"><figcaption></figcaption></figure>

4. Click on Finish and save.

<figure><img src="../../../../.gitbook/assets/image (1759).png" alt="" width="437"><figcaption></figcaption></figure>

5. All elements will be captured in the test step group

<figure><img src="../../../../.gitbook/assets/image (1760).png" alt=""><figcaption></figcaption></figure>

### FOR SAP

1. Click on **New test step group** and select **Record new test step group**
2. Avo genius window will pop-up. Select **Application type as SAP** and **Provide Application Path. Click Start Recording.**

<figure><img src="../../../../.gitbook/assets/image (1762).png" alt=""><figcaption></figcaption></figure>

3. Avo Genius(SAP) window will pop up with another window to enter username and password.

<figure><img src="../../../../.gitbook/assets/image (1) (2).png" alt="" width="563"><figcaption></figcaption></figure>

4. Once recording is complete. Provide Folder name and testcase name and Click Save.

<figure><img src="../../../../.gitbook/assets/image (2) (3).png" alt="" width="563"><figcaption></figcaption></figure>

5. All Elements will be saved in the test Case step.

<figure><img src="../../../../.gitbook/assets/image (3) (2).png" alt=""><figcaption></figcaption></figure>
