# Creating Test Case

To create a new Test Case in Avo Assure, perform the following actions:

1. On the **Home** page, under **Projects**, select the required Project.
2. Select **Design Studio**. Select the **Test Case** tab, locate the **Create Folder** (**+**) icon.
3. Select **Create Folder** (**+**) icon and select **Create main folder** to create a new folder for Test case. A new folder is created.

<figure><img src="../../../.gitbook/assets/image (4924).png" alt=""><figcaption></figcaption></figure>

4. In the **New Folder** text box, enter the Test case folder name.
5. In the newly created folder, select **Ellipsis** (**...**) icon > **Create Test case** > to create the Test case.

<figure><img src="../../../.gitbook/assets/image (4925).png" alt=""><figcaption></figcaption></figure>

6. In the **New Test case** text box, enter the Test case name.

<figure><img src="../../../.gitbook/assets/unknown (3) (1) (1).png" alt=""><figcaption></figcaption></figure>

7. Select **Create Test Step Group** and then choose one of the available methods to create the Test Steps.
   * [Adding New Test Step Group](create-test-step-group/add-new-test-steps-group.md)
   * [Add Test Step Group from Reusable Library](create-test-step-group/add-test-steps-group-from-reusable-library.md)
   * [Record Test Step Group Using Avo Genius](create-test-step-group/record-test-step-group-using-avo-genius.md)
8. Select **Save** to save the Test Steps.
