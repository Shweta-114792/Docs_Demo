# Assign Reused Test Step Group

1. Expand Reusable Library
2. Select **Folder**
3. Click **...** icon and select **Assign** **Reusable steps groups** from context menu&#x20;

<figure><img src="../../../../.gitbook/assets/Screenshot 2025-06-18 103733.png" alt=""><figcaption></figcaption></figure>

4. Choose user from dropdown to assign the reused Test Step Group&#x20;

<figure><img src="../../../../.gitbook/assets/Screenshot 2025-06-18 103751 (1).png" alt=""><figcaption></figcaption></figure>

5. Click **Assign**
