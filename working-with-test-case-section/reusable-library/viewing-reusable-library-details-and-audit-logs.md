# Viewing Reusable Library Details and Audit Logs

The reusable library details help you understand the key information related to a reusable library. You can view details such as the reused test step group name, description, status, creation date, time, and the user who created it.

The reusable library audit logs track the history of changes made to reusable library folder or reused test step groups.

This document includes:

* [Viewing Reusable Library Details](viewing-reusable-library-details-and-audit-logs.md#viewing-reusable-library-details)
* [Viewing Reusable Library Audit Logs](viewing-reusable-library-details-and-audit-logs.md#viewing-reusable-library-audit-logs)

## Viewing Reusable Library Details

To view the reusable library details, perform the following actions:

1. On the **Home** page, from **Projects** list, select required project.
2. Select **Design Studio**.
3. Select **Test Case**.
4. On the **Test Case** page, expand the **Reusable Library** and select the reused test step group for which you want to see the details.

![](<../../../.gitbook/assets/unknown (287).png>)

5. Select the **Information Panel** (**i**) icon. The **Details** tab opens.

![](<../../../.gitbook/assets/unknown (288).png>)

6. On the **Details** tab, you can view the following information:

* **Reused Test Step Group Name**: The reused test step group name.
* **Description**: The reused test step group description.
* **Status**: The reused test step group status (New, In Progress, Under Review, Approved or Rejected).
* **Created On**: The reused test step group creation date and time.
* **Created By**: The username of the person who created the reused test step group.

![](<../../../.gitbook/assets/unknown (289).png>)

## Viewing Reusable Library Audit Logs

To view the reusable library audit logs, perform the following actions:

1. On the **Home** page, from **Projects** list, select required project.
2. Select **Design Studio**.
3. Select **Test Case**.
4. On the **Test Case** page, expand the **Reusable Library** and select the reused test step group for which you want to see the details.

![](<../../../.gitbook/assets/unknown (287).png>)

5. Select the **Information Panel** (**i**) icon. The **Details** tab opens.

![](<../../../.gitbook/assets/unknown (288).png>)

6. Select the **Audit Logs** tab.

![](<../../../.gitbook/assets/unknown (292).png>)

7. Select **Date Range** to view the actions performed between the specified dates.

![](<../../../.gitbook/assets/unknown (293).png>)

8. Expand the month to view the actions performed in the test case.

![](<../../../.gitbook/assets/unknown (294).png>)

### Audit Log Inclusions

The following actions are captured in the reusable library audit logs:

* Performing Folder Level Actions
* Creating Reusable Library
* Renaming Reusable Library
* Reordering Test Steps from Reusable Library
* Assigning or Reviewing History

### Audit Log Exclusions

The following actions are currently not captured in the reusable library audit logs:

* Modifying Test Steps
