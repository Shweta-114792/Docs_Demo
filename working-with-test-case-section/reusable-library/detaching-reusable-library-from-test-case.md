# Detaching Reusable library from Test Case

Below are the steps to detach Reusable library from test Case:

1. Select **Test Step Group** created by you. In the right panel, Click **Detach.**

<figure><img src="../../../../.gitbook/assets/image (2600).png" alt=""><figcaption></figcaption></figure>

2. This **Test Step Group** will be detached from the Reusable library.
