# Reusable Library

The Reusable Library in Avo Assure is automatically available in every test case within a project and serves as a centralized repository for reusable test step groups. By creating reusable step groups, you can reduce duplication, improve script maintenance, and promote consistency across test cases. This article explains the different ways to create a Reusable Library, how to use it in test cases, detach it when required, view its details and audit logs, and assign reused test step groups.
