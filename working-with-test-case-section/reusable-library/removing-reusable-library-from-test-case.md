# Removing Reusable library from Test Case

Below are the steps to remove Reusable library from test Case:

1. Select **Test step Group** created by you. In the right panel, Click **Remove.**

<figure><img src="../../../../.gitbook/assets/s3 (1).png" alt=""><figcaption></figcaption></figure>

2. This Test **step Group** will be removed from the Reusable library
