# Edit Element Attributes in Test Case

To edit the attributes perform the following action:

1. On **Home** page, under **Projects**, select required project.
2. From upper right corner, select **Design Studio** to open the **Test Case** page.
3. Select Test Case from folder.
4. Navigate to **Test Step Group**.
5. Under **Elements** column, hover over any captured element.
6. Select **i** icon. Details pane opens on the right side of the Test Case page.

<figure><img src="../../../.gitbook/assets/unknown (117).png" alt=""><figcaption></figcaption></figure>

6. On the **Details** pane, select Repository Path to navigate to Element Repository.

<figure><img src="../../../.gitbook/assets/unknown (118).png" alt=""><figcaption></figcaption></figure>

7. On the **Element Repository** page, hover over the element for which you want to edit the attribute.
8. Select the **edit** icon, **Details** pop up window appears.

<figure><img src="../../../.gitbook/assets/unknown (119).png" alt=""><figcaption></figcaption></figure>

9. On the Details pane, edit the attributes and select **Save Properties**.

<figure><img src="../../../.gitbook/assets/unknown (120).png" alt=""><figcaption></figcaption></figure>

10. Select **Redirect to test case** button to redirect to the Test Case window.

<figure><img src="../../../.gitbook/assets/unknown (121).png" alt=""><figcaption></figcaption></figure>
