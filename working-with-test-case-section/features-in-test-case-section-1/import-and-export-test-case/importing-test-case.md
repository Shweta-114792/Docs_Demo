# Importing Test Case

The process to import Test steps are:

1. Navigate to Test cases window in design studio
2. Select Test step group by expanding the folder located in left pane of the screen and click import icon ![](<../../../../.gitbook/assets/image (1725).png>)
3. Click Choose File button, select Json file from your system and click Import button.
