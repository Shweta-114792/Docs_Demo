# Exporting Test Case

### **Export Test Steps**

Step-by-step process to import test steps:

1. Navigate to Test cases window
2. Select Test step group by expanding the folder located in left pane of the screen and click Export icon ![](<../../../../.gitbook/assets/image (1731).png>)
3. Click Export button and exported file will be saved in downloads folder in local machine
