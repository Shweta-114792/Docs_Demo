# Viewing Test Case Details

To view the test case details, perform the following actions:

1. On the **Home** page, from **Projects** list, select required project.
2. Select **Design Studio**.
3. Select **Test Case**.
4. On the **Test Case** page, expand the required folder and select the test case for which you want to see the details.
5. Select the **Information Panel** (**i**) icon. The **Details** tab opens.

![](<../../../../.gitbook/assets/unknown (295).png>)

6. On the **Details** tab, you can view the following information:

* **Test Case Name**: The test case name.
* **Description**: The test case description.
* **Tags**: The test case tags.
* **Status**: The test case status (New, In Progress, Under Review, Approved or Rejected).
* **Created On**: The test case creation date and time.
* **Created By**: The username of the person who created the test case.
