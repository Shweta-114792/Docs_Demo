# Data Parametrization

Data parametrization in Avo Assure allows you to create flexible test scripts by replacing hardcoded values with variables. This enables the reuse of the same test script with different inputs, enhancing test coverage, flexibility, efficiency, and scalability.

### This document includes:

**Prerequisites**

The pre-requisites to follow for performing Data Parametrization

**Ways to Achieve Data Parametrization**

Different ways to perform data parametrization in Avo Assure

### Pre-requisites

1. Avo Assure Client must be installed and connected with Avo Assure&#x20;
2. Excel sheet/Data Table should be created&#x20;
3. Ensure Excel path/Data Table path is ready for access&#x20;

### Ways to Achieve Data Parametrization

In Avo Assure, there are two different ways to achieve Data Parametrization:

1. [Through Excel Sheet](through-excel-sheet.md)&#x20;
2. [Through Data Table ](through-data-table.md)
