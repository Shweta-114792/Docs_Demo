# Review Test Case

The Send for Review feature in Avo Assure enables you to submit a test case for evaluation or validation by another team member. It supports a structured review workflow that helps ensure test case quality and accuracy before execution or finalization. Authors can send test cases for review, while reviewers can evaluate the test case, provide feedback, and decide whether to approve or reject it. This article explains how to send a test case for review and how reviewers can review, accept, or reject the submitted test case.

{% hint style="info" %}
**Note:**

* A Testcase is always sent to review only to a user with the role As Quality Manager or Quality Lead in Avo Assure.
* Ensure that the selected reviewer is a member of the same project.
{% endhint %}
