# Ways to invoke and use Avo Genius

In Avo Assure you have three ways to use Avo Genius:&#x20;

1. [**From landing page of Avo Assure**](ways-to-invoke-and-use-avo-genius.md#from-landing-page-of-avo-assure)
2. [**By Clicking + icon present in Test Cases window**](ways-to-invoke-and-use-avo-genius.md#by-clicking--icon-present-in-test-cases-window)
3. [**By clicking View more after creating Test case**](ways-to-invoke-and-use-avo-genius.md#by-clicking-view-more-after-creating-test-case)

### From landing page of Avo Assure

1. From **New Test case** card, select **Create new test case**.
2. Select **Avo Genius Record** option.

<figure><img src="../../../.gitbook/assets/image (5027).png" alt=""><figcaption></figcaption></figure>

### By Clicking + icon present in Test Cases window

1. Click **Design Studio button** from top right corner of Assure instance and navigate to Test Cases tab.
2. Click **" +" icon** and select **Create new folder to** create a **unique** **folder**&#x20;
3. Click **on three dots beside the folder** and select **Record with Avo Genius** option.

### By clicking View more after creating Test case

1. Click **Design Studio button** from top right corner of Assure instance and navigate to Test Cases window.
2. Create a **New Folder** with **Test case.**
3. Click **View more icon** and click **Record with Avo Genius button** to use Avo Genius.
