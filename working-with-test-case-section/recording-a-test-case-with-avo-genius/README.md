# Recording a Test Case with Avo Genius

Avo Genius, a key feature of Avo Assure, it’s simplifying the creation of automated test cases. It works as an intelligent recorder, capturing user interactions with web or SAP applications and converting them into test cases automatically. This feature is designed to making it suitable for both technical users and those with little or no coding experience.
