# Exploring Home Page

The Home page is the main place in Avo Assure where you can easily access and manage your automation work. It appears after you sign in and helps you manage projects, create test assets, configure integrations, and view project-related information from one place.

It helps you quickly navigate through different sections of the platform, manage testing activities, and track project progress easily. This article provides an overview of the Home page and describes the available sections, components, and their functionalities.

### Home Page Overview

The Home page divides into the following sections:

| Areas             | Descriptions                                                                                                                                                                                                                                                                                                                                                                 |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Workspace Section | <p>Displays information related to the selected project, including <strong>Manage Users</strong>, <strong>Manage Integrations</strong>, <strong>Test Case</strong> creation, <strong>Element</strong></p><p><strong>Repository</strong> creation, <strong>Dashboard Information</strong>, <strong>Execution Profiles</strong>, and <strong>Execution Summaries</strong>.</p> |
| Left Section      | Displays **Project** information and provides access to **Home**, **Utility**, and **Admin** options.                                                                                                                                                                                                                                                                        |
| Top Section       | Displays **Profil**e icon along with **Notifications** icon for reviewed test artefacts.                                                                                                                                                                                                                                                                                     |
