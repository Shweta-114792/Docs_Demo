# Sorting Projects



User can arrange the project according to **Date/Alphabet/Last Modified**

To sort projects in Avo Assure, follow the steps below.

1. Click the **Sort icon** in the landing page to rearrange the project sequence.
2. Filter the projects based on the date it is created, **Last Modified, Date Created** or **Alphabetical** order to bring up the projects as per the selection.
