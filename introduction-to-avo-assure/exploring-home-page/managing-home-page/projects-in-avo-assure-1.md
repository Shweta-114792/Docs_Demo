# Copying Project Link

The copy project link allows you to share direct links to the home page with the project details. Opening a project link automatically restores the selected project, even after a page refresh or when opened in a new browser tab. Access to the linked page is determined by your project assignment and permissions. This article explains how to copy and use project links for quick access and collaboration.

{% hint style="info" %}
**Note**:

* When you share a project link with a user, the user must be added to the project.
* You must log in to the Avo Assure instance to access a project's direct link.
{% endhint %}

To copy project link, perform the following actions:

1. On the **Home** page, from **Projects** list, select required project.
2. On the browser address bar, select the project link.
3. Press **Ctrl + C** Key combination on the keyboard. The link gets copied.
