# About the Dashboard

The Dashboard provides a centralized view of your automation activities. It allows you to monitor project activity, track execution results, analyse trends, and review status information from a single location. The dashboard also allows you to filter and view data based on different criteria, such as date range, project, creator, and assigned user.

The Dashboard displays information through multiple widgets. Each widget presents specific data to give insights into different aspects of testing and execution. This article walks you through the Dashboard in Avo Assure. It explains the key components of the Dashboard interface and describes the purpose of the available user interface (UI) controls, enabling users to interpret the displayed information effectively.

On the **Home** page (Dashboard), you can do the following:

1. **Filters**: Allows you to filter dashboard data based on the selected criteria.
2. **Date Range**: Allows you to filter dashboard data for a specific time period.
3. **Bitbucket Integration**: Allows you to filter data based on Bitbucket integration.
4. **Created By**: Allows you to view data created by a specific user.
5. **Assigned To**: Allows you to view data assigned to a specific user.
6. **Projects**: Allows you to select a project and view dashboard data associated with the selected project.
7. **Download**: Allows you to download the dashboard data.
8. **Refresh**: Allows you to refresh the dashboard and view the latest dashboard data. The **Last refreshed** timestamp displays the most recent dashboard refresh time in UTC.
9. **Save View**: Allows you to save the currently selected dashboard filters and preferences for future sessions. The saved view is automatically applied when you log in.
10. **Reset to Default**: Allows you to remove the saved dashboard filters and preferences and restore the default dashboard view.
11. **Element Repositories**: Allows you to view metrics and detailed insights related to element repositories.
12. **Edit Widgets**: Allows you to customize the widgets displayed in Element Repositories section. You can add or remove widgets based on your requirements.
13. **Total Repositories**: Allows you to view the total number of element repositories.
14. **Remove Widget**: Allows you to remove the Total repositories widget.
15. **App Type**: Allows you to select a specific application type and view the corresponding dashboard data.
16. **Open Repositories**: Allows you to navigate to the **Element Repository** page and view the available repositories.
17. **Resize Widgets**: Allows you to adjust the size of widgets to customize the dashboard layout. Drag the widget border or corner to resize the widget.
18. **Move widgets**: Allows you to move widgets and arrange them in the preferred order on the dashboard. Select and drag a widget to move it to the required location on the dashboard.
19. **Element Repository Status**: Allows you to view the [status](../../../../create-and-execute-tests-with-design-studio/test-artifacts-in-avo-assure.md) of element repositories.
20. **Remove Widget**: Allows you to remove the Element repository status widget.
21. **Chart Type**: Allows you to view the element repository status data in Horizontal Bar, Pie, or Donut format.
22. **Filter Element Repository Status**: Allows you to filter the element repository status data based on the following criteria:
    * Date Range
    * Bitbucket Integration
    * Created by
    * Assigned to
23. **Element Repository Trends**: Allows you to view the element repository creation trend for the selected time period.
24. **Remove Widget**: Allows you to remove the Element repository trends widget.
25. **Chart Type**: Allows you to view the element repository trends data in Line, Bar, or Area format.
26. **Filter Element Repository Trends**: Allows you to filter the element repository creation trend data based on the following criteria:
