# Viewing the Dashboard

The Dashboard section allows you to filter and view data based on the selected criteria. This article explains how to access the Dashboard and view data using available dashboard sections, widgets, and filters, enabling users to analyze information and understand trends effectively.

## Viewing Dashboard Filters

The Dashboard filters allow you to refine and view dashboard data based on specific criteria, such as project, date range, creator, and assigned user.

To view and access the Dashboard filters, perform the following actions:

1. On the **Home** page, locate **Dashboard overview**.
2. In the **Dashboard overview** section, view the **Filters** dropdown section.
3. Select a date from the **Date Range** date picker to choose the required start date and end date for which you want to view dashboard data.
4. Select the **Bitbucket** integration toggle to view data based on Bitbucket integration status.
5. From the **Created by** multi-select dropdown, select the required user to filter and view data created by the specific user.

{% hint style="info" %}
**Note**: Use the **Select All** check box to select all available users.
{% endhint %}

6. From the **Assigned to** multi-select dropdown, select the required user to filter and view data assigned to the specific user.

{% hint style="info" %}
**Note**: Use the **Select All** check box to select all assigned users.
{% endhint %}

7. From the **Projects** multi-select dropdown, select the required project.

{% hint style="info" %}
**Note**:

* Use the **Select All** check box to select all available projects.
* By default, a project is automatically selected when you log in to the application.
{% endhint %}

8. Select **Save filters** to save the selected filter criteria. A success message appears.
9. Select **Clear filters** to remove all the applied filters.

{% hint style="info" %}
**Note**:

* Select **Download** to download the dashboard data.
* Select **Refresh** to reload the dashboard data and display the latest updates.
* You can view the **Last refreshed** timestamp to verify the latest dashboard refresh time in UTC.
{% endhint %}

After applying the required filters, the Dashboard displays data based on the selected filter criteria.

## Viewing Element Repositories Data

The Element Repositories section allows you to view element repository-related metrics, element repository status, and element repository creation trends.

To view and access the Element Repositories data, perform the following actions:

1. On the **Home** page, locate **Dashboard**.
2. In the **Dashboard** section, scroll to the **Element Repositories** dropdown section.
3. In the **Total repositories** widget, you can view the total number of element repositories based on the applied dashboard filters.
4. From the **App Type** multi-select dropdown, select the required application type for which you want to view repository data.
5. Select **Open repositories**. The **Element Repository** page opens, and you can view the available repositories.
6. In the **Element repository status** widget, you can view the element repository [status](../../../../create-and-execute-tests-with-design-studio/test-artifacts-in-avo-assure.md) data.
7. Select the **Chart Type** icon and choose the required chart type to view the element repository status data in the selected chart format.
8.  Select the **Element repository status** filter icon. The **Filter Element repository status** dialog opens. In the **Filter Element status** dialog, perform the following actions:

    1. Select a date from the **Date Range** date picker to choose the required start date and end date.
    2. Select the **Bitbucket integration** toggle to view data based on Bitbucket integration status.
    3. From the **Created by** multi-select dropdown, select the required user to filter and view data created by the specific user.

    **Note**: Use the **Select All** check box to select all available users.

    4. From the **Assigned to** multi-select dropdown, select the required user to filter and view data assigned to the specific user.

    **Note**: Use the **Select All** check box to select all assigned users.

    5. Select **Apply** to apply the selected filters.
    6. Select **Clear** to remove the applied filters.
9. In the **Element repository trends** widget, you can view the trend of element repositories created by each user over the selected time period.
10. Select the **Chart Type** icon and choose the required chart type to view the element repository trends data in the selected chart format.
11. Select the **Element repository trends** filter icon. The **Filter Element repository trends** dialog opens. In the **Filter Element repository trends** dialog, perform the following actions:

    1. Select a date from the **Date Range** date picker to choose the required start date and end date.
    2. Select the **Bitbucket integration** toggle to view data based on Bitbucket integration status.
    3. From the **Created by** multi-select dropdown, select the required user to filter and view data created by the specific user.

    **Note**: Use the **Select All** check box to select all available users.

    4. From the **Assigned to** multi-select dropdown, select the required user to filter and view data assigned to the specific user.

    **Note**: Use the **Select All** check box to select all assigned users.

    5. Select **Apply** to apply the selected filters.
    6. Select **Clear** to remove the applied filters.

After applying the required filters, the selected widgets display element repositories data based on the specified criteria.

## Editing a Widget

To add or remove widgets in a dashboard section, perform the following actions:

1. In the required dashboard section, select the **Edit** icon. The **Edit** dialog box opens.

<img src="../../../../.gitbook/assets/unknown (328).png" alt="" height="288" width="528">

2. Select the checkbox for the widgets that you want to display in the section.
3. Clear the checkbox for the widgets that you do not want to display in the section.
4. Alternatively, select the **Select all** checkbox to add all available widgets to the section.
5. Select **Save changes**. The dashboard section displays the selected widgets.

## Removing a Widget

To remove a widget, perform the following actions:

1. Locate the widget that you want to remove.
2. Select the **Remove** icon on the widget. The **Remove widget** confirmation dialog box opens.

<img src="../../../../.gitbook/assets/unknown (329).png" alt="" height="172" width="605">

3. Select **Remove** to remove the widget. The selected widget is removed from the dashboard section.

{% hint style="info" %}
**Note**: Select **Cancel** to close the dialog without removing the widget.
{% endhint %}
