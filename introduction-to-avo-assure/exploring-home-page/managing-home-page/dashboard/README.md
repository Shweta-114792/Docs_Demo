# Dashboard

The Dashboard serves as a central interface for accessing and interacting with automation data in Avo Assure. It provides access to key metrics, status indicators, trends, and summary data through a collection of interactive widgets and filters. This section provides an overview of how the Dashboard is organized and how users can interact with its components.
