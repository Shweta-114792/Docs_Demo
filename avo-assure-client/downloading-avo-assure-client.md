# Downloading Avo Assure Client

You can download the Avo Assure Client based on your user type  :

* [**Downloading Client for New User**](downloading-avo-assure-client.md#downloading-client-for-new-user)
* [**Downloading Client for Existing User**](downloading-avo-assure-client.md#downloading-client-for-existing-user)

## Downloading Client for New User

To download the Avo Assure Client, perform the following actions:

1. On the **Avo Assure Login** page, enter your **Username** and **Password**.

{% hint style="info" %}
**Note**: If you enter an invalid password multiple times, then your account gets locked. To unlock your account, you must reach out to Admin.
{% endhint %}

2. Select **Login**. The **Accept Terms and Conditions** dialog opens.

{% hint style="info" %}
**Note**: Only users with the **Admin** role or the **Quality Manager** with Admin as a secondary role can create a new user. To learn more, [click here](../../administration/authentication-configuration/authentication-configuration-1/privileges.md).
{% endhint %}

3. Select **I Agree** to accept the terms and conditions. Once confirmed, you are directed to the **Download Avo Assure Client** page.

<figure><img src="../../.gitbook/assets/image (4699).png" alt=""><figcaption></figcaption></figure>

4. Select **Download Avo Assure Client** to download the **AvoAssureClient.exe** file.

{% hint style="info" %}
**Note**: If you do not want to download the **AvoAssureClient.exe** file at this time, select **Skip for now**. You are then directed to the **Getting Started** page.
{% endhint %}

<figure><img src="../../.gitbook/assets/image (4701).png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
**Note**: After the download completes, the **AvoAssureClient.exe** file appears in the browser **Downloads** section.
{% endhint %}

<figure><img src="../../.gitbook/assets/image (4700).png" alt=""><figcaption></figcaption></figure>

5. Select **Open**, **Save As**, or **Save** to save it in the **Downloads** folder on local machine.
6. On the **Setup Avo Assure Client** page, select the **>** icon to view the next setup steps.
7. Once the **Next** button appears, select **Next**. The **Getting Started** page opens.

{% hint style="info" %}
**Note**:

* If you do not want to view the setup steps, select **Skip** to direct you to the **Getting Started** page. For detailed installation instructions, [click here](installing-avo-assure-client.md).
* If the download does not start automatically, you can get it from the **User Profile** dropdown on the **Home** page.
{% endhint %}

<figure><img src="../../.gitbook/assets/image (4869).png" alt=""><figcaption></figcaption></figure>

8. Select **Get Started** to complete the client download process.

<figure><img src="../../.gitbook/assets/image (4703).png" alt=""><figcaption></figcaption></figure>

## Downloading Client for Existing User

To download the Avo Assure Client, perform the following actions:

1. On the **Home** page, select the **Profile** icon.
2. Select **Download**, and then select **Download** **Client**. The download automatically begins.

{% hint style="info" %}
**Note**: After the download completes, the **AvoAssureClient.exe** file appears in the browser **Downloads** section.
{% endhint %}

3. Select **Open**, **Save As**, or **Save** to save it in the **Downloads** folder on your local machine.
4. The **AvoAssureClient.exe** file is downloaded.
