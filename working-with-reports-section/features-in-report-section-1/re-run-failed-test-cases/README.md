# Re-run Failed Test Cases

The **Re-run Failed Test Cases** feature in Avo Assure improves test execution efficiency by allowing you to automatically re-execute only the test cases that failed during an execution profile. Instead of rerunning the entire execution profile, you can target only the failed test cases, reducing execution time, optimizing resource usage, and helping you identify genuine issues more quickly. This article explains the feature and its capabilities, describes how to re-run failed test cases, and provides best practices for using the feature effectively.
