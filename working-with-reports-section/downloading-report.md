# Downloading Report

There are three detailed report download options available in Avo Assure – Json, PDF and PDF with screenshot formats.

1. Navigate back to the Report tab and click Testcase Details icon, to bring up Run details popup window in top right corner of Reports tab.

<figure><img src="../../../.gitbook/assets/image (2503).png" alt=""><figcaption></figcaption></figure>

2. Click Download Testcase Details icon, from Run Details pop up window

<figure><img src="../../../.gitbook/assets/image (2504).png" alt=""><figcaption></figcaption></figure>

2. Select required format from the pop to download the reports

<figure><img src="../../../.gitbook/assets/image (2505).png" alt=""><figcaption></figcaption></figure>

{% hint style="warning" %}
**Note:**&#x20;

_For Test cases, the reports can be downloaded in JSON, PDF and PDF with screenshots formats._

_The browser/client name is now visible in all report formats—HTML, PDF, detailed PDF, and email attachments._
{% endhint %}
