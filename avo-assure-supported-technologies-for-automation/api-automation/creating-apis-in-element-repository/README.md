# Creating APIs in Element repository

This section explains how to create a APIs in a Element Repository. It provides step-by-step guidance on configuring API requests, including defining endpoints, selecting HTTP methods, adding headers, setting up authentication. It also describes how to import an API definition from the local system and URL to build a complete API configuration. &#x20;

To create API request in Element Repository, you can use the following options:

* [**Creating New API Request** ](creating-new-api-request.md)
* [**Importing APIs Definition**](importing-apis-definition.md)
