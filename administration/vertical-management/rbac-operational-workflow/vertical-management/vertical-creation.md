# Vertical Creation

### Vertical Creation&#x20;

1. Login to Avo Assure with an Account admin-level account. &#x20;

<figure><img src="../../../../.gitbook/assets/image (364).png" alt=""><figcaption></figcaption></figure>

2. In the Admin panel, expand the Vertical Management section.

<figure><img src="../../../../.gitbook/assets/image (365).png" alt="" width="341"><figcaption></figcaption></figure>

3. Click on Vertical to open the vertical configuration screen.

<figure><img src="../../../../.gitbook/assets/image (366).png" alt=""><figcaption></figcaption></figure>

4. Click the “Add New Vertical” button (at the top-right corner).

<figure><img src="../../../../.gitbook/assets/image (367).png" alt=""><figcaption></figcaption></figure>

5. In Create Vertical pop up, enter the Vertical Name (e.g., Banking, Insurance, Retail) and Description for the vertical (e.g., “Handles banking domain projects”).

<figure><img src="../../../../.gitbook/assets/image (368).png" alt="" width="563"><figcaption></figcaption></figure>

6. Click Create button to complete vertical creation. The vertical will now appear in the list and can be used for assigning users, projects, and agents
