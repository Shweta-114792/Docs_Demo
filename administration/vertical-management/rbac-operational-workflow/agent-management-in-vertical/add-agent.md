# Add Agent

### Steps to Add agent for new vertical:&#x20;

1. Navigate to Admin and select Agent Management from Vertical Management section.&#x20;
2. Select Vertical from dropdown&#x20;

<figure><img src="../../../../.gitbook/assets/image (388).png" alt=""><figcaption></figcaption></figure>

3. Click Add Agents button to select and add the Agent

<figure><img src="../../../../.gitbook/assets/image (389).png" alt=""><figcaption></figcaption></figure>

4. Select the Agent and check active/inactive toggle button of the respective Agent (_Agent must be active_)

<figure><img src="../../../../.gitbook/assets/image (390).png" alt=""><figcaption></figcaption></figure>

5. Click **Save** button

{% hint style="info" %}
**Note:** The **Avo Agent** automatically updates to the latest version. Reinstallation is not required when a new version is available.
{% endhint %}
