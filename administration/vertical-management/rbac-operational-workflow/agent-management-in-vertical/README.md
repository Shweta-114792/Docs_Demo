# Agent Management in Vertical

Agent Management in Avo Assure is the process of configuring, registering, and monitoring test execution agents. Agents are environments where test cases are run. It helps ensure that tests execute in the correct platform.

Agent Management enables users to activate or deactivate agents, track their online/offline status, and assign them efficiently. It is essential for distributing workloads, enabling parallel execution, and improving test scalability. This ensures faster, reliable, and well-coordinated automation execution across multiple systems.
