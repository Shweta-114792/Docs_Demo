# Session Management

Avo Assure session management feature is used to view user status and gain insight into Active Users, Active Avo Assure Clients, and Locked Users in Avo Assure.

### [Roles that can access session management](authentication-configuration-1/privileges.md)

* Admin
* Quality Manager with Admin as secondary role

The steps to check the status of active user

[Check Active Avo Assure Client](session-management.md#check-active-users-avo-assure-client-and-locked-users)

The steps to check the status of active Avo Assure Client

[Check the Locked User](session-management.md#check-active-users-avo-assure-client-and-locked-users)

### Access session management

To access session management window, follow the steps below:

1. Navigate to the Admin section on the left pane of the landing page
2. Navigate to Session Management window
