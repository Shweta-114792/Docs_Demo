# Account Management

This section covers Authentication Configuration function in Avo Assure which includes LDAP and SAML configurations, and how to edit or delete these configurations. This feature helps the users to onboard into Avo Assure.

### Roles that can access [SSO Management](authentication-configuration-1/privileges.md)

* Admin
* Quality Manager with Admin as secondary role
