# License Details

This document covers the License Details function in Avo Assure. It contains a user's current license status, including the type of license, subscription details, license status, and validity. Additionally, users can check the status of the features available, indicating whether they are enabled or disabled.

Avo Assure provides 4 types of licenses for its users depending upon the features required for the users to perform different actions.&#x20;

| Licenses            | Descriptions                                                                                                                                                                                                                                                |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Trial License       | Users can access or evaluate features and functionalities available in Avo Assure for a limited period.                                                                                                                                                     |
| Training License    | Users can access and use the Avo Assure for learning and instructional purposes.                                                                                                                                                                            |
| Starter License     | This license type is tailored for individuals, small businesses or beginners with limited need or resources. Up to five users can access Avo Assure using this license.                                                                                     |
| Enterprise License  | This license is tailored for large organizations or enterprises. It provides comprehensive access to Avo Assure, often with additional features and benefits compared to a starter license. More than five users can access Avo Assure using this license.  |

The step-by-step process to find the details of the current license and its Enable/Disabled Features are:&#x20;

1. Navigate to the **Admin** section on the left pane of the landing page
2. Navigate to **User Management** in the **Admin** section&#x20;
3. Click on License Details to get the details associated with a user license
