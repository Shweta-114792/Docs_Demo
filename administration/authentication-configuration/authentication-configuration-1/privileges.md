# Privileges

To view the privileges of all user roles, perform the following actions:

1. On the **Home** page, in the left pane, select **Admin** and select **Configuration**.

<figure><img src="../../../.gitbook/assets/unknown (206).png" alt=""><figcaption></figcaption></figure>

2. Select the **Privileges** tab to view the user roles and their permissions.
