# Project Management

In Avo Assure, creating projects helps streamline testing by providing a structured framework for managing resources, timelines, and team roles.

### [Roles that can work with creating & Maning project:](../authentication-configuration-1/privileges.md)

Two user roles who can manage project in Avo Assure are:

1. Admin
2. Quality Manager with Admin as secondary role
