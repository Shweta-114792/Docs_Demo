# Create Project

### Overview of creating project

Creating a project in Avo Assure is important because it allows us to assign tasks, manage resources, and track progress effectively. This way, we can ensure that our testing is thorough and directly linked to project requirements, leading to better quality software and improved teamwork.

### Steps to Create Project

1. Click + icon to navigate to Create Project window to create new project.
2. Enter Project Name, enter Description of project, select Users from the left-hand column and assign them role from Project level role drop down. Then click (>) arrow icon to assign user to project and click Create button it will create new project and displayed on landing page
