# Manage Project

Below are the Steps to Manage Project:

1. Navigate to Admin Section of your Assure instance
2. Click **Project Management** to bring up Assigned Projects window

<figure><img src="../../../.gitbook/assets/image (4190).png" alt=""><figcaption></figcaption></figure>

2. Select User from Username drop-down menu, to assign team members to specific projects

For flexible team configurations based on project needs, any user can be added or removed from required projects.

{% hint style="info" %}
**Note:**

* User must be assigned project to access the Project.
* These arrows (>, <) are used to move single project from All Projects to Assigned Project
* These arrows (>>, <<) are used to move all the project from All Projects to Assigned Project & vice versa.
{% endhint %}

4. Click Save button after assigning or unassigning the project to the user.

<figure><img src="../../../.gitbook/assets/image (1588).png" alt=""><figcaption></figcaption></figure>

### Delete Project

Below are the steps to Delete Project:

1. Navigate to **Admin** section and click **Project Management** option

<figure><img src="../../../.gitbook/assets/Screenshot 2025-08-28 122420.png" alt=""><figcaption></figcaption></figure>

2. Click **Delete Projects** tab

<figure><img src="../../../.gitbook/assets/Screenshot 2025-08-28 122713.png" alt=""><figcaption></figcaption></figure>

3. Select Project from list which needs to be deleted
4. Click **Delete** button
