# Design Studio

Design Studio is intuitive, all-in-one workspace equipped with a robust **Element Repository, Test case, Execution** and **Report**s. This feature allows to capture, and store captured elements to use them when creating Test cases hence executing and debug them with ease. It also has reporting tool features for users to get detailed report of the execution to get valuable insights and enhance the overall design and testing process.

## **Viewing Design Studio**

To view the Design Studio, perform the following actions:

1. On the Avo Assure home page
2. Select **Design Studio** Button. The All options are available.
